# SourLang Types (Conceptual)

This document lists the basic data types planned for SourLang and their properties.

- **`char`**:
  - Size: 1 byte
  - Representation: Typically ASCII or UTF-8 character.
- **`byte`**:
  - Size: 1 byte
  - Representation: Unsigned integer (0 to 255).
- **`int`**:
  - Size: 4 bytes
  - Representation: Signed integer.
